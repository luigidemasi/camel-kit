Red Hat build of Apache Camel 4.14 for Spring Boot 3 GA

Red Hat build of Apache Camel for Spring Boot is tested and verified with:

  • Red Hat OpenShift Container Platform (OCP)
  • Red Hat Enterprise Linux (RHEL)
  • Microsoft Windows Server
  • Spring Boot 3.5.9
  • JDK 17, JDK 21
  • More details in Red Hat build of Apache Camel 4 Supported Platforms

Red Hat build of Apache Camel 4.14 for Spring Boot 3 Supported Messaging Providers

The following messaging providers were tested with Red Hat build of Apache Camel for Spring Boot:

Broker Supported version Tested version Messaging client version
Red Hat AMQ Broker 7.x 7.13, 7.12 artemis-jakarta-client: 2.40.0
qpid-jms-client: 2.7.0
Red Hat streams for Apache Kafka 2.x, 3.x 2.7.0, 3.1.x kafka-client: 3.9.1
IBM Websphere MQ 9.x 9.4.2 9.4.2
Red Hat Data Grid 8.5.5 8.5.5, 8.5.3 infinispan-client-hotrod: 15.0.19

Note: Red Hat tests messaging providers using the messaging driver versions shown above. These drivers are typically compatible with a range of message broker versions. See your vendor’s documentation for information about driver compatibility with specific server versions.


Red Hat build of Apache Camel 4.14 for Spring Boot 3 Supported Database Integrations

The following databases were tested with Red Hat build of Apache Camel for Spring Boot:

Database Supported versions Tested versions JDBC drivers
PostgreSQL All supported by the JDBC driver 17.7, 14.5, 13.2 JDBC Postgresql Driver 42.7.8
MySQL All supported by the JDBC driver 8.0 MySQL Connector 9.5.0
MariaDB All supported by the JDBC driver 10.6, 10.3 MariaDB Java Client 3.5.6
Microsoft SQLServer Linux All supported by the JDBC driver 2022, 2019 MS SQL Server JDBC Driver 12.10.2 JRE 11
Oracle All supported by the JDBC driver 19cR3 Oracle JDBC Driver 23.7.0.25.1
DB2 All supported by the JDBC driver 11.5 IBM Data Server Driver for JDBC and SQLJ 12.1.3.0
MongoDB All supported by the JDBC driver 4.4.5 MongoDB Driver 5.5.2

Agroal and HikariCP are the recommended JDBC connection pools for Red Hat build of Apache Camel for Spring Boot. The versions of both connection pools are managed by the Red Hat build of Apache Camel for Spring Boot BOM.

Note Red Hat tests database integrations using the JDBC driver versions shown above. These drivers are typically compatible with a range of database server versions. See your database vendor’s documentation for information about JDBC driver compatibility with specific server versions.
