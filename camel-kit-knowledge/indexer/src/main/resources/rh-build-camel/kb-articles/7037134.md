# Red Hat build of Apache Camel 4.14 GA

Red Hat build of Apache Camel 4.14 GA is tested and verified on Quarkus and Spring Boot runtime frameworks.

- [Configurations supported on Red Hat build of Apache Camel 4.14 for Quarkus 3.27](https://access.redhat.com/articles/6507531#camel-414-ga)
- [Configurations supported on Red Hat build of Apache Camel 4.14 for Spring Boot 3.5](https://access.redhat.com/articles/6970899#camel-414-ga)

## Red Hat build of Apache Camel 4.14.x Supported and Tested Platforms

In order to be running in a supported configuration, Red Hat build of Apache Camel including its [components](https://access.redhat.com/articles/7036995) such as HawtIO must be running on one of the following JVMs and operating systems:

| JVM                                               | Operating System / Platform   | Chipset Architecture                                             | Supported version                                                              | Tested version                      | Container image                                                       |
|---------------------------------------------------|-------------------------------|------------------------------------------------------------------|--------------------------------------------------------------------------------|-------------------------------------|-----------------------------------------------------------------------|
| Red Hat OpenJDK 17, 21  Eclipse TemurinJDK 17, 21 | Red Hat Enterprise Linux      | x86\_64,  [[7]](#footnote7)  aarch64                             | 8, 9                                                                           | 8.8, 9                              |                                                                       |
| Red Hat OpenJDK 17, 21                            | Red Hat OpenShift             | x86\_64,  [[6]](#footnote6)  s390x ,  [[6]](#footnote6)  ppc64le | 4.12 (extended support), 4.14 (extended support), 4.16, 4.17, 4.18, 4.19, 4.20 | 4.12 (extended support), 4.18, 4.20 | ubi8/openjdk-17,  ubi8/openjdk-21,  ubi9/openjdk-17,  ubi9/openjdk-21 |
| Red Hat OpenJDK 17, 21  Eclipse TemurinJDK 17, 21 | Microsoft Windows Server      | x86_64                                                           | 2019, 2022                                                                     | 2022                                |                                                                       |
| Red Hat OpenJDK 17, 21  Eclipse TemurinJDK 17, 21 | [[3]](#footnote3)  Other      | x86_64                                                           |                                                                                |                                     |                                                                       |

Red Hat build of Apache Camel is supported on the following variants of Red Hat OpenShift

- Red Hat OpenShift Container Platform (OCP), including all related subscriptions like OpenShift Kubernetes Engine (OKE) or bundles like OpenShift Platform Plus
- Red Hat OpenShift Service on AWS (ROSA classic and HCP)
- Microsoft Azure Red Hat OpenShift (ARO)
- Red Hat OpenShift Dedicated (OSD)
- Red Hat Device Edge 4 - Microshift 4.18 on x86 [[4]](#footnote4)
- IBM Power (ppc64le), IBM Z (s390x), and IBM® LinuxONE (s390x) architectures are supported with Red Hat OpenShift

Red Hat build of Apache Camel 4 for Quarkus is also supported to run in Quarkus native mode. See [Red Hat build of Apache Camel for Quarkus Supported Configuration](https://access.redhat.com/articles/6507531) for more details.

Red Hat build of Apache Camel 4 supports running on FIPS-enabled Red Hat OpenJDK 21 on RHEL8. For more details see [KCS article](https://access.redhat.com/solutions/7033368) .

Red Hat build of Apache Camel 4 supports running in air-gapped (offline) environments. Building Camel applications on Spring Boot in offline environment is available through Offline Maven Repository Builder. See [this KCS](https://access.redhat.com/solutions/7068331) for usage instructions.
