# Camel YAML DSL — Structure & Kaoto Compatibility

This guide defines the structural rules for valid Apache Camel YAML DSL that is compatible with Kaoto and `camel run`.

---

## Kaoto Compatibility Requirements

### 1. Use Standard Camel YAML DSL Format

```yaml
- route:
    id: route-id
    from:
      uri: component:path
      steps:
        - step1
        - step2
```

### 2. Use `steps:` Array Format (Not Inline)

```yaml
# Correct - Kaoto will render each step as a node
steps:
  - unmarshal:
      json: {}
  - filter:
      simple: "${body.active}"
  - to:
      uri: kafka:output
```

### 3. Use Explicit `uri:` and `parameters:` Structure

```yaml
# Correct - Kaoto can edit parameters visually
from:
  uri: kafka:orders
  parameters:
    brokers: "{{KAFKA_BROKERS}}"
    groupId: order-processor
```

### 4. Use Object Format for EIPs (Not Shorthand)

```yaml
# Correct - Kaoto shows all properties
- filter:
    simple: "${body.amount} > 100"
    steps:
      - to:
          uri: direct:process
```

### 5. Include Route Metadata

```yaml
- route:
    id: order-ingestion              # Required - shown in Kaoto
    description: Process orders...    # Shown as tooltip/description
    from:
      ...
```

### 6. Use Standard EIP Names

| Correct (Kaoto) | Avoid |
|-----------------|-------|
| `filter` | `when` (standalone) |
| `choice` with `when`/`otherwise` | `if`/`else` |
| `split` | `foreach` |
| `to` | `send` |
| `setHeader` | `header` |
| `setBody` | `body` |
| `transform` | `map` |

### 7. Nested Steps Structure

For EIPs with nested processing, always use `steps:` array:

```yaml
- split:
    simple: "${body.items}"
    steps:
      - log:
          message: "Processing ${body}"
      - to:
          uri: direct:process-item
```

### 8. Error Handler at Route Level

```yaml
- route:
    id: my-route
    errorHandler:
      deadLetterChannel:
        deadLetterUri: kafka:dlq
    from:
      uri: kafka:input
      steps:
        - to:
            uri: jpa:Order
```

### 9. File Header

```yaml
# Generated by camel-kit
# Project: my-integration
# Camel Version: 4.18.0
# Open in Kaoto: https://kaoto.io
# Run with: camel run routes.camel.yaml
```

## Basic Route Structure

### Single Route

```yaml
- route:
    id: route-id
    description: Route description text
    from:
      uri: component:destination
      parameters:
        option1: value1
      steps:
        - step1
        - to:
            uri: sink:destination
```

### Multiple Routes

```yaml
- route:
    id: first-route
    from:
      uri: kafka:orders
      steps:
        - to:
            uri: direct:process

- route:
    id: second-route
    from:
      uri: direct:process
      steps:
        - to:
            uri: jpa:Order
```

## Source Transformation

### Component Source

```yaml
from:
  uri: kafka:orders
  parameters:
    brokers: "{{KAFKA_BROKERS}}"
    groupId: order-processor
```

### Kamelet Source

```yaml
from:
  uri: kamelet:kafka-source
  parameters:
    bootstrapServers: "{{KAFKA_BROKERS}}"
    topic: orders
```

### Internal Source (direct/seda)

```yaml
from:
  uri: direct:process-order
```

## Data Format Transformation

### Unmarshal (Deserialize)

**JSON:**
```yaml
- unmarshal:
    json:
      unmarshalType: com.example.Order
```

**JSON (without type):**
```yaml
- unmarshal:
    json: {}
```

**XML:**
```yaml
- unmarshal:
    jaxb:
      contextPath: com.example.model
```

**CSV:**
```yaml
- unmarshal:
    csv:
      useMaps: true
```

### Marshal (Serialize)

```yaml
- marshal:
    json:
      prettyPrint: true
```
