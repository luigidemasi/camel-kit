# Validate Mode Rules

- Validate routes against `docs/constitution.md`, design specs, generated reports, and project norms.
- Use `camel-reviewer` for isolated route, security, and graph analysis, including MCP calls needed by a review lane.
- Do not modify route or application code in validation mode.
- Write only validation report markdown and required Camel-Kit document metadata.
- Report findings with severity and concrete file references.
