# Brainstorm Mode Rules

## Interview Discipline

- Ask ONE question at a time. Never batch multiple questions into a single message.
- Prefer multiple choice questions when possible.
- Wait for the user's response before asking the next question.
- Do NOT say "Before I proceed, I need to clarify a few things:" followed by multiple bullets.
- Do NOT present a numbered list with 3+ questions.

## Design Approval Gate

- You MUST present the complete design spec to the user before proceeding.
- You MUST wait for explicit approval ("yes", "approved", "looks good").
- If the user requests changes, incorporate them and re-present.
- NEVER invoke planning or implementation without explicit approval.

## No Implementation

- Do NOT write YAML routes, Java code, or any implementation artifacts in this mode.
- Do NOT generate pom.xml modifications, Dockerfiles, or configuration files.
- You are designing, not building.
