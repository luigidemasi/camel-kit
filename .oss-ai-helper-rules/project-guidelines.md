# Project Guidelines

This file contains branching, commit, and PR policies for the camel-kit project.

- Fix branch naming pattern: `fix/<short-description>`
- Feature branch naming pattern: `feature/<short-description>`
- Bugfix branch naming pattern: `fix/<short-description>`
- Quick-fix branch naming pattern: `quick-fix/<short-description>`
- CI-fix branch naming pattern: `ci-issue/<short-description>`
- Documentation branch naming pattern: `docs/<short-description>`
- Command branch naming pattern: `command/<command-name>`
- Template branch naming pattern: `template/<template-name>`
- Commit format (fix): clear and descriptive message
- Commit format (quick-fix): `[chore]: <brief description>`
- Commit format (ci-fix): `[ci]: <brief description>`
- PR creation policy: always
- Find-task source: GitHub labels
- Find-task beginner label: `good first issue`
- Find-task experienced label: `help wanted`
- Scope-too-large redirect: `/oss-create-issue`

## PR Requirements

- Descriptive PR title
- Fill out the PR template
- Link related issues
- Request review from maintainers
- Tests pass locally
- Documentation updated (if applicable)
- CHANGELOG.md updated (for significant changes)
- Commit messages are clear and descriptive
