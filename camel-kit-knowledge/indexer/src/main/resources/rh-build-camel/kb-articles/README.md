# KB Articles — Manual Download

These Knowledge Base articles require a Red Hat account and must be
downloaded manually.

## Instructions

1. Log in to [access.redhat.com](https://access.redhat.com)
2. Open each article URL below in your browser
3. Save the page as **HTML Only** (`Ctrl+S` / `Cmd+S` → select "Webpage, HTML Only")
4. Place the saved `.html` files in this directory (`kb-articles/`)
