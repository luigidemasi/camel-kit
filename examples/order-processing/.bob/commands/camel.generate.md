## Step 3: Transform to YAML

For each route, transform the specification to Camel YAML DSL.

**Key transformation rules:**

1. **Source** → `from.uri` with `parameters`
2. **Processing steps** → nested under `from.steps`
3. **Sink** → `to` element in steps
4. **Error handling** → `errorHandler` at route level
5. **Environment variables** → `{{VARIABLE}}` syntax

**EIP nesting rules (for Kaoto compatibility):**

- Filter, Split, Choice → child steps go under `steps` array
- Expressions → use `simple`, `jsonpath`, etc. as key

---

## Step 4: Generate YAML File

Create `routes.camel.yaml`:

```yaml
# Generated by camel-kit
# Compatible with Kaoto visual designer
# Run with: camel run routes.camel.yaml

- route:
    id: order-ingestion
    description: Process orders from Kafka and store in database

    errorHandler:
      deadLetterChannel:
        deadLetterUri: kafka:orders-dlq
        redeliveryPolicy:
          maximumRedeliveries: 3
          redeliveryDelay: 1000

    from:
      uri: kafka:orders
      parameters:
        brokers: "{{KAFKA_BROKERS}}"
        groupId: order-processor
      steps:
        - unmarshal:
            json:
              unmarshalType: com.example.Order

        - filter:
            simple: "${body.totalAmount} >= 50"
            steps:
              - circuitBreaker:
                  resilience4jConfiguration:
                    failureRateThreshold: 50
                  steps:
                    - to:
                        uri: http://customer-service/api/customers/${body.customerId}
                  onFallback:
                    - setBody:
                        constant: '{"status": "fallback"}'

              - to:
                  uri: jpa:com.example.Order

- route:
    id: order-notification
    description: Send notifications for processed orders

    from:
      uri: direct:notify
      steps:
        - to:
            uri: smtp:notifications
            parameters:
              to: "{{ADMIN_EMAIL}}"
              subject: "Order ${body.orderId} processed"
```

## YAML Transformation Reference

Use this reference when transforming route specs to YAML:

### Source Transformation

Route spec:
```
Source: kafka-source Kamelet
  bootstrapServers: {{KAFKA_BROKERS}}
  topic: orders
```

YAML:
```yaml
from:
  uri: kamelet:kafka-source
  parameters:
    bootstrapServers: "{{KAFKA_BROKERS}}"
    topic: orders
```

### Processing Steps

Route spec:
```
1. Unmarshal JSON → com.example.Order
2. Filter: ${body.totalAmount} >= 50
3. Enrich: http://customer-service/api
```

YAML:
```yaml
steps:
  - unmarshal:
      json:
        unmarshalType: com.example.Order
  - filter:
      simple: "${body.totalAmount} >= 50"
      steps:
        - to:
            uri: http://customer-service/api
```

### Error Handling

Route spec:
```
Strategy: Dead Letter Channel
Destination: kafka:orders-dlq
Max Retries: 3
```

YAML:
```yaml
errorHandler:
  deadLetterChannel:
    deadLetterUri: kafka:orders-dlq
    redeliveryPolicy:
      maximumRedeliveries: 3
      redeliveryDelay: 1000
```

### Choice (Content-Based Router)

Route spec:
```
Route based on order type:
- If type == "express" → direct:express
- If type == "standard" → direct:standard
- Otherwise → direct:default
```

YAML:
```yaml
- choice:
    when:
      - simple: "${body.type} == 'express'"
        steps:
          - to:
              uri: direct:express
      - simple: "${body.type} == 'standard'"
        steps:
          - to:
              uri: direct:standard
    otherwise:
      steps:
        - to:
            uri: direct:default
```

### Circuit Breaker

Route spec:
```
External call with circuit breaker:
  URL: http://customer-service/api
  Fallback: return empty response
```

YAML:
```yaml
- circuitBreaker:
    resilience4jConfiguration:
      failureRateThreshold: 50
      waitDurationInOpenState: 30000
    steps:
      - to:
          uri: http://customer-service/api
    onFallback:
      steps:
        - setBody:
            constant: '{}'
```

### Split and Aggregate

Route spec:
```
Split by items array, process each, aggregate back
```

YAML:
```yaml
- split:
    jsonpath: "$.items"
    steps:
      - to:
          uri: direct:process-item
    aggregate:
      strategy: groupedBodyAggregator
```
